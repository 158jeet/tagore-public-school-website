# Tagore Group website (TIER)

Independent Next.js application for https://www.tieredu.org.

## Local development
`npm install` then `npm run dev`.

## Deployment
Set the deployment root directory to `apps/tier`. The production domain remains unchanged until the new site has passed acceptance and the owner approves cutover.

## Content safety
Institution details are intentionally conservative. Do not publish unverified history, enrolment totals, awards, fees, contact routing, facilities, rankings or testimonials. Confirm institution taxonomy and official contact details before launch.

## Brand assets
Replace the typographic placeholder mark with the exact approved Tagore Group logo asset. Do not redraw or distort the logo.
